# V5 performance experiments

These tools generate evidence, not an OBS advantage claim. Use a disposable copy of a world. Do not run GPU experiments concurrently with a game measurement. Keep raw outputs, including bad runs; explain exclusions.

## Implemented tools

- `gradlew.bat scaleBenchmark`: standalone hidden OpenGL 3.3 context, 4K→1080p, 1080p→1440p and 1080p→1080p. Compares production-style linear framebuffer blit/vertical flip with a single bilinear shader triangle. Twenty warmup pairs and 100 randomized measured pairs per repeat, three repeats, seed 51. GPU timer queries block **only in this separate experimental program**. Output: `build/scale-benchmark/{samples.csv,quality.csv,environment.txt,*.png}`. Gradient plus three-pixel checkerboard verifies both orientation and sampling. Pixel difference is against the other method, not an ideal resampling reference. This does not test sophisticated antialiasing filters, in-game state changes, FFmpeg conversion or total frame impact.
- `gradlew.bat runClient -Pbenchmark=record -PbenchmarkWorld="Optic V4 Validation" -PbenchmarkSeconds=30 -PbenchmarkLabel=record-1`: fixed 1280×720 window, saved player position, smooth ±45° camera yaw, 15-second world warmup, five-second encoder warmup, bounded 240,000-sample raw interval buffer. Records Balanced 1080p/60/Standard/Auto, full HUD, audio off. Output trace in `run/v5-benchmark/<label>-<time>/`; video and support artifacts in separate `v5-benchmark-videos` / `v5-benchmark-videos-details`. Video settings are temporary. Window/focus preferences restore at completion. The harness closes its own client when finished.
- Change `-Pbenchmark=idle` for loaded-but-idle Optic. `obs` runs exactly the same idle workload and labels it for an **externally configured and already recording OBS**; it does not start OBS or verify its settings. Do not label this mode an OBS result without checking the recording.
- `powershell -File benchmarks/Run-Local.ps1 -Seconds 30`: seeded order of three idle/record pairs; stops on launch/trace failure. Defaults to the disposable `Optic V4 Validation` world. Actual world simulation still advances; restore identical world snapshots outside the measured interval for rigorous repeatability. A replay workload would be preferable but Flashback is not required or yet certified.
- `powershell -File benchmarks/Summarize.ps1`: exact sample percentiles, mean FPS, slowest-1%-mean FPS, maximum and measured duration. Flags unfocused/overflowed runs invalid. Does not silently discard them. Each run receives equal reporting weight; do not pool all frames across unequal runs.

The recorder's per-session metrics now separate polling from submission and report unique FPS, scale copy count and black-bar clear count. `frameIntervals` measures every game render tick, not only frames selected for recording. Raw trace times surround successive pre-present hooks: useful CPU/game pacing evidence, **not measured display presentation latency**.

## Fair OBS comparison protocol

1. Preserve a clean world snapshot and exact game configuration. Log Minecraft/Fabric/mod versions, CPU/GPU, RAM/VRAM, OS/driver, AC/battery and power profile, thermal state, window size, display refresh, VSync/FPS cap, render/simulation distance and shader pack. Disable unrelated background jobs. Warm chunks, shader compilation and encoders. Keep the game foreground; reject minimized/unfocused runs. Record the reason for every excluded run.
2. Run four conditions: mod absent; mod installed idle; Optic recording; OBS recording while Optic idle. For mod-absent and all others, use the **same external presentation/frame collector** (for example Intel PresentMon) because an Optic trace cannot exist with Optic absent. Include a saved V4 checkout/binary as an additional historical comparator when available. This working directory has no immutable V4 build to reconstruct honestly.
3. Configure OBS game capture, same GPU/encoder, H.264, output dimensions/FPS, keyframe interval, preset/tuning, scaling filter and equivalent audio. Disable preview only if reported. Compare ordinary full-HUD output first; OBS cannot necessarily reproduce V4 exclusions. Do not compare an excluded Optic overlay with an unrelated OBS scene workload. No second active Optic encoder in OBS runs.
4. Quantizer numbers and named presets are not equivalent across encoders. Retain FFmpeg/OBS effective options, sample output and bitrate. First match codec/backend/settings as closely as possible; then inspect moving foliage, particles, UI text and dark gradients, and compare perceptual quality against a shared reference. Report mismatches rather than presenting a quality sacrifice as a speed win. Balanced currently uses NVENC p4/CQ23 when selected; inspect the session manifest's encoder and videoOptions because auto may select another encoder. Early V5 test manifests predate the added videoOptions field; the codec/quality and source revision supply their options.
5. Randomize at least three repeats per condition. Use ≥60-second measured runs after warmup for comparisons, longer for thermal equilibrium; retain each trace and uncertainty (range or confidence interval), not only the best run. Log CPU utilization, process working/private memory, dedicated/shared GPU memory, GPU 3D/copy/video encode utilization and disk throughput with the same external sampler. The built-in trace does not measure these and must not substitute zeroes.
6. Report average FPS, 1% low FPS, p50/p95/p99 frame time, maximum stalls, unique encoded FPS, duplicates/drops, actual bitrate and A/V continuity. Compare deltas against idle and mod-absent baselines. CPU hook duration alone misses GPU contention. Check queue/memory plateau during a long run.
7. Target: less than 1% missing unique frames under sustainable foreground load, bounded memory, no render-thread waits/disk/encoding, and equal-or-lower frame-time impact than OBS within uncertainty on explicitly tested configurations. Publish cases where OBS wins. Overloaded 120 FPS or background-throttled runs are failures of that configuration, not successful 120 FPS capture because duplicate frames fill the file.
